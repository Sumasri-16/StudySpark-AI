
# StudySpark AI 📚

## Overview
StudySpark AI is an AI-powered study assistant that converts study notes into revision flashcards and multiple-choice quizzes.

## Features
- Paste study notes or upload a PDF
- Generate five flashcards
- Generate five multiple-choice questions
- Check answers and view explanations
- Download study material as JSON

## Technologies
- Python
- Streamlit
- Google Gemini API
- PyPDF
- python-dotenv

## Run Locally
1. Install Python.
2. Install dependencies:
   `pip install streamlit google-genai pypdf python-dotenv`
3. Create a `.env` file containing your API key:
   `GEMINI_API_KEY=your_api_key`
4. Start the application:
   `python -m streamlit run app.py`

Never upload your API key or `.env` file.
